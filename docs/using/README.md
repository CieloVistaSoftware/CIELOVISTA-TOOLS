# Using it

Everything is a `cvs.` command. The **CieloVista: Home** page lists the ones
that are actually registered right now, which is the fastest way to see what
you have.

<!-- docs-sync:begin -->

- **[Doc Catalog](view-a-doc.md)** — Searchable catalogue of documentation across every registered project.
- **[Feature catalogue](features.md)** — Every feature in the extension and the commands it registers.
- **[Issue Viewer](issueviewer.md)** — Browse, filter and act on GitHub issues without leaving the editor.
- **[Turning off the background health runner](disable-background-health-runner.md)** — How to stop the hourly health checks and auto-filed issues.

<!-- docs-sync:end -->

Not finding a command on the Home page means it is not registered — the page
filters to live commands on purpose, so what you see is what exists.
